## 12. Krav før slutteksamen

Før studenten kan få tillatelse til slutteksamen, skal følgende krav være oppfylt:

* [ ] Nødvendig opplæring gjennomført.
* [ ] Obligatoriske kurs bestått.
* [ ] Minimum én uke studentperiode gjennomført.
* [ ] Tilstrekkelig praktisk tjeneste gjennomført.
* [ ] **3 godkjente rapporter.**
* [ ] **3 godkjente straffesaker.**
* [ ] Erfaring som **OPL \[Operasjonsleder]**.
* [ ] Erfaring som **Forhandler**.
* [ ] Erfaring som **Sikrer**.
* [ ] Tilfredsstillende kompetanse demonstrert.
* [ ] Vurdert som klar av ansvarlig instruktør eller ledelse.



## 13. Slutteksamen

Slutteksamen er den avsluttende vurderingen av studentens kunnskap og ferdigheter og kan bestå av både teoretiske og praktiske oppgaver.

Studenten skal vise forståelse for politiets rolle, grunnleggende prosedyrer og praktisk anvendelse av det som er lært.

Dersom eksamen ikke bestås, kan videre opplæring og ny vurdering bli aktuelt før et nytt forsøk.
